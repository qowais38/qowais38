## Featured projects

### [FairSplit](https://github.com/qowais38/fairsplit)

A shared trip expense app with personal dashboards, manager approvals, and payments tracked in **PKR**.

- Record bills paid by one person or multiple contributors.
- Submit member expenses for manager approval before splitting costs across the group.
- Track who owes money and who should receive it; only the recipient can confirm a repayment.
- Complete trips and generate saved receipts that members can view, print, or save as PDF.

**Built with:** React, Vite, Tailwind CSS, Node.js, Express, and MongoDB.

**Checks:** API integration tests, Playwright browser flows, and automated builds with GitHub Actions.

[Explore the project and setup guide →](https://github.com/qowais38/fairsplit#readme) · [View automated checks →](https://github.com/qowais38/fairsplit/actions/workflows/ci.yml)

### [FindMyTutor](https://github.com/qowais38/FindMyTutor)

A tutor discovery platform with Student, Teacher, and Admin workspaces.

- Search and save tutors, then view full profiles after login.
- Manage teacher profiles and Admin approvals.
- Chat in real time and share ratings and reviews.
- Store accounts, conversations, and feedback in MongoDB.

**Built with:** React, Tailwind CSS, Node.js, Express, MongoDB, and Socket.IO.

[Explore the project, screenshots, and setup guide →](https://github.com/qowais38/FindMyTutor#readme)
